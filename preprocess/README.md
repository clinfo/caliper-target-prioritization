# Preprocessing boundary

The paper-scale preprocessing route requires local copies of the external resources described in `data/README.md`. The source repository contained exploratory and historical notebooks, but they are not included in this public release because they mix non-paper label routes and local working assumptions.

The public Route B begins from a user-prepared external-data layout and the paper templates in `config/paper/`. `docs/reproducibility.md` gives the supported input families, identifier mappings, and expected intermediate products. It does not claim a one-command raw-download-to-paper workflow.

Do not place external raw files, large intermediates, or notebook checkpoints in this repository.
